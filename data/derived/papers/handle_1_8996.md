# Machine Learning for Evaluating Critical Data Literacy in Open Online Learning Environments

**Conference:** ISLS 2022

## Abstract & Introduction

### Abstract
The study highlights the application of machine learning in assessing critical data literacy in an open online learning network. The study uses Support Vector Machine algorithm to build a predictive model based on a labeled dataset with students’ comments on data visualizations. Features that indicate reflection and curiosity can be used with machine learning algorithms to assess the level of critical data literacy in activities that are adaptive to data representation.

## Introduction

The use of data visualizations in education is vast ly growing and its application in online learning c ommunities is becoming more and more prevalent. In response to this trend, the ability for students to critically reflect, reason and make sense of data is significant in today's learni ng and teaching processes (Ben-Zvi & Arcavi, 2001; Kjelvik & Schultheis, 2019). This implies that the development of critical data literacy is imperative in order to nurture competent problem solvers and well-informed digital citizens. Critical data literacy goes beyond the ability to use data, it entails the ability to reason and demonstrate higher order thinking and evaluate data in rich contexts (Hautea et al., 2017). As much as there has been a surge of open learning environments that use data visualizations for teaching and learning, there is still a gap in effective assessment of how  students engage and demonstrate critical data lite racy in these contexts. We therefore take advantage of machine learning to assess critical data literacy since it presents potential in conducting evaluations of complex environments (Zha i et al., 2020). In this study we base our investig ation on an open learning network, New York Times Learning Network (Peralta et al., 2021), by extracting students’ comments from the following four data visualization activiti es: Climate Threats (Network, T. L., 2020a), World Citi es’ Air Pollution (Network, T. L., 2021), U.S Wellbeing (Ne twork, T. L., 2020b), and First Vaccinated (Network, T. L., 2020c). The main objective of this study is to highlight how machine learning can be used to assess the demonstration of critical data literacy in open learning environm ents. The main research question guiding this study  is: How can machine learning be used to assess learners’ critical data literacy in open online learning environments?

## Method

The source dataset consisting of 1024 student responses from New York Times Learning Network data visualization activities was used for building a machine learning  model. Since the analysis took the form of supervi sed learning, the dataset consisted of a human-labelled column called More Information. Kappa was found to be above 0.8 for this label, indicating good reliability. The label relates to the extent to which the student demonstrates curiosity about other data that the featured visualization did not show. This could be a future trend or when the student sought more contexts to interpret data trends. The column had binary lab els of “1” and “0”. Label “1” for the comments that  indicated demonstration of data literacy and “0” for those that did not indicate a connection to critical data literacy. The study deployed a cross-validation train-test approach to split the dataset into two parts at 67% and 33% respectively. The modelling process was done on LightSIDE, which is a n open-source machine learning application for text classification (Mayfield & Rosé, 2013). The initial process involved feature extraction from the training dataset that included 687 observations. The feature configurations were primarily set to unigrams and included punctuations to account for the nature of the prediction exercise which is intended to classify text based on the demonstrated level of curiosity. In this phase a set of 3092 features from the training dataset were extracted as a feature table. The baseline model was built by the Support Vector Machines (SVM) algorithm it was tested on a dataset containing 3 37 observations. The competing model had the accuracy of 73.77 % and Kappa statistic of 0.27.  In order to improve the model, the second feature extraction was performed and at this time, basic feature configuration was s et to include “bigrams”. The new constructed model had a marginal  improvement with accuracy of 76.33% and Kappa of 0.31 (p=.077, t=1.773).

## Findings

ICLS2022 Proceedings 1920 © ISLS The exploration of the confusion matrix (Mayfield & Rosé, 2013) was performed to identify features that can be used to predict critical data literacy in online learnin g platforms. The analysis and identification of fea tures was done by considering two elements in LightSIDE, feature weight and frequency. The ideal predictive feature should have high frequency and weight. An analysis of instances cont aining the features was also performed in order to evaluate the contextual application and to validate the classification.  The main identified features were “I_wonder” with feature weight of 0.30 and frequency of 168. This makes the  feature a prominent predictor since this combination of words can be associated with curiosity in evaluating data visualizations. The second predictive feature is “graph” which has feature weight of 0.25 and frequency of 152. The feature is a feasible predictor since in analyzed instances, students referred to visualization in their descriptive responses which can be an indication of deep reasoning with data (Lee et al.,2021). The other identified feature is “countries” which had frequency of 24 and weight of 0.148. While tracking this feature in the instances, it was noted that students did comparative analysis between the U.S and other countries which demonstrates application of critical data lit eracy. Based on these results, we can conclude that, students candemonstrate deep reasoning by expressing curiosity in their descriptive responses and by making contextual references to examined data visualizations in the learning environment. However, despite these results, we have to acknowledge that there are still some gaps, both in the modeling task and in the quality of student responses in the platforms. In the testing set, there are 52 instances that did not in dicate critical data literacy. There is an urgent n eed of developing innovative open learning resources that can support building capacities in critical data literacy.

## Conclusion

The increased use of data visualizations in education drives the need for developing innovative solutions for assessing students’ demonstration of critical data literacy. The results of this study indicate that machine lea rning provides promising approaches for evaluating critical data l iteracy in open learning environments. Features tha t indicate reflection and curiosity can be used with machine l earning algorithms to assess the level of critical data literacy in activities that are adaptive to data representation. The study also calls for the need to develop open  educational resources that can support building critical data literacy for students.
