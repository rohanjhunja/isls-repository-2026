# Mirror Agents: A Dynamic Metacognitive Multi-Agent Framework for Real-Time Metacognitive Development

**Conference:** ISLS 2025

## Abstract & Introduction

### Abstract
This research introduces a novel multi-agent framework, "Mirror Agents," to support K-12 students' metacognitive development through dynamic, real-time scaffolding. Building on the MAPS model, the system deploys four specialized agents—Guide, Progress, Reflection, and Strategy—that collaboratively monitor and respond to learners' cognitive and metacognitive activities. Unlike traditional systems offering static feedback, Mirror Agents continuously synthesize cognitive mirroring data (learning behaviors and outcomes) with metacognitive mirroring data (strategy use and self-regulation). Through multimodal inputs—including behavioral indicators, interface interactions, and physiological signals—the framework creates a comprehensive mirror of students' learning processes. This study explores patterns of metacognitive monitoring emerging from agent interactions and examines how learners adapt strategies in response to multi-agent feedback. The framework advances current educational technologies by offering a dynamic, interconnected agent model that enhances real-time metacognitive growth and provides design principles for intelligent learning environments.

## Introduction

The intersection of metacognition and multi-agent systems presents a novel frontier in educatio nal technology, particularly in how learners develop self-understanding through technological “mirrors”. While traditional metacognitive development relies heavily on self-reflection and external feedback, multi-agent systems offer a dynamic, real-time mirror that can potentially transform how learners perceive and adjust their cognitive processes (Hamal et al., 2021). Drawing upon the MAPS model (Frazier et al., 2021), which integrates metacognition, agency, possible selves, and behavior, this researc h proposes an innovative approach to metacognitive development through interactive agent-based mirrors. Traditional measurement tools for me tacognition, while valuable, often capture static snapshots rather tha n the fluid, interactive nature of cognitive  process and learning experiences (Duffy & Azevedo, 2015). Our Mirror Agents framework advances existing agent-based educational systems by providing continuous, dynamic metacognit ive scaffolding rather than static or episodic feed back. While traditional systems often support cognition in isolation, our framework integrates four specialized agents— Guide, Progress, Reflection, and Strategy—to collaboratively support real-time metacognitive development. This model uniquely combines cognitive mirroring data (l earning activities and outcomes) with metacognitive mirroring data (strategy usage and self-regulatory behaviors), forming interconnected feedback loops. As such, it offers a theoretically grounded and practically adaptive system that deepens learner support and contributes to the design of intelligent educational  technologies focused on metacognitive growth.  Our proposed model with interaction and monitoring frameworks will examine  two research questions: (1) What patterns of metacognitive monitoring emerge during agent interactions? (2) How do learners' strategies adapt to multi-agent feedback loops? The Mirror Agents model The Mirror Agent Model (see Figure 1) integrates MAPS components through four specialized agents supporting metacognitive development. Operating through User B ehavior Data and Agent Generation Data streams, the system enables continuous adaptation through interc onnected feedback loops. The Guide Agent orchestrat es learning pathways, the Progress Agent monitors beha viors, the Reflection Agent promotes self-awareness, and the Strategy Agent scaffolds metacognitive development from basic to expert levels. The system operates through two primary data streams: User Behavior Data capturing learning activities and metacognitive states, and Agent Generation Data synthesizing feedback and adaptive support. These streams feed into interconnected feedback loops that enable  continuous system adapt ation. The bidirectional monitoring between agents, particularly the Progress-Strategy connection, ensures responsive metacognitive support. Figure 1 The Mirror Agents Model Dynamic interaction framework of Mirror Agents The interaction framework (see Figure 2) establishe s collaboration between agents and learners through  multilevel interactions. The Guide Agent functions as the system's "brain," coordinating objectives and resources, while other agents handle monitoring,  evaluation, and strategy optimization. Through soli d arrows (direct information flows) and dotted arrows (conditional feedback), the framework creates a dynamic environment for metacognitive development.

Figure 2 The Mirror Agents Interaction Framework Monitoring framework in the feedback loop of Mirror Agents The monitoring framework establishes a comprehensiv e data collection and analysis system that integrat es both cognitive and metacognitive dimensions through our multi-agent architecture. For cognitive mirroring, the system captures direct learning activiti es and outcomes through real-time behavioral monitoring, performance metrics, and resource utilization patterns. This data flows primarily through the Progress Agent, which tracks learning trajectories and feeds information to other agents for dynamic support adjustments. Mirror Agents comprises a more complex data ecosystem, incorporat ing multiple strategy dimensions: self-planning (including FOK and goal-setting mechanisms)  (Langlois et al., 2020), self-monitoring (utilizing JOL and MPTG frameworks)  (Taub et al., 2014), self-regulation (through self-testing and content evaluation), and self-direction (via strategy selection and adjustment pr otocols). The system employs sophisticated data collection methods, including user interface intera ctions, multimodal inputs (text, voice, behavioral signals), and physiological measures (EDA, EEG), creating a rich dataset for metacognitive assessment (Rakovic et al., 2022). Each agent serves a specialized role in this data processing framework. While the Progress Agent focuses on real-time behavioral and assessment data collection, the  Reflection Agent analyzes strategy implementation and effectiveness. The Guide Agent integrates these  insights for learning path optimization, and the S trategy Agent synthesizes findings into actionable metacogn itive recommendations. This orchestrated approach e nables dynamic feedback loops between cognitive and metaco gnitive processes, supporti ng real-time adjustments to learning strategies and pathways, ultimately creating a responsive, personalized learning environment that adapts to individual metacognitive development needs.
