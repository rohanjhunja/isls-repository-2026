# Identifying Challenges and Interaction Issues in a Generative AI-Assisted Code Description Activity for Programming Beginners

**Conference:** ISLS 2025

## Abstract & Introduction

### Abstract
This study investigates the challenges programming beginners face when using Generative AI to describe coding intentions. We analyzed data from 120 students where students described problems, and AI generated code. Performance was evaluated across 48 tasks in eight categories using metrics. Our findings indicate that tasks in the “dictionaries” category are the most challenging for beginners. Additionally, we identified recurring interaction issues such as ambiguous instructions, assumptions about AI understanding, and misalignment with code logic.

## Introduction

In recent years, the integration of Generative AI i nto educational tools has opened new pathways for l earning, particularly in the field of programming education (Petrovska et al., 2024; Phung et al., 2023). “Charlie the Coding Cow” is one such platform, where participants inter act with a Generative AI to describe their coding i ntentions, generate code, and evaluate its accuracy (Nguyen et al., 2023). Through this activity, learners are able to acqui re and apply programming concepts with the assistance of AI. However, programming beginners often face specific challenges, particularly in the task of articulatin g their coding intentions to the AI, which  can lead to interaction issues. This study aims to explore the key challeng es that programming beginners encounter during Gene rative AI-assisted code description activities and to analyze the interaction problems that arise between students and AI during this process. The specific research questions are as follows:

• RQ1: Among the coding tasks, which specific tasks d o programming beginners find most challenging

when using GenAI to describe their coding intentions?

• RQ2: What issues arise in the interaction between students and Generative AI during the code description

activity?

## Research context

In the study, researchers created a web application  called “Charlie the Coding Cow,” based on OpenAI’s  Codex model, to experiment with how programming novices s olve problems using AI. In this platform, students were presented with problems one at a time, and by descr ibing the problem in natural language, the AI would  convert it into code. There were 120 participants, all students enrolled in a CS1 course. The main experiment consisted of eight problems: Lists, Loops, Strings, Conditionals, Math, Nested, Sorting, and Dictionaries.

## Conclusion

This study analyzed the challenges faced by programming beginners when using Generative AI to describe coding intentions, as well as the interaction issues with AI. The “dictionaries” category and the “student_grades” problem were identified as the most ch allenging tasks. A qualitative analysis of students ' programming outcomes, along with prompt and response data, highlights the need to explore effective strategies to help novice prog rammers successfully complete tasks.
