# Using Learning Analytics in Understanding College Students’ Behavior in ChatGPT-Facilitated Programming Learning

**Conference:** ISLS 2024

## Abstract & Introduction

### Abstract
As a typical generative artificial intelligence tool, ChatGPT has gained wide attention in its application to programming. However, few researchers have conducted empirical studies to explore how learners use ChatGPT for programming learning. This study analyzes learners' programming learning behaviors to explore the characteristics of different performance learners using ChatGPT-assisted programming learning. The study analyzes the programming process of 15 learners adopting the fine-grained programming behavior method. The results indicate that: (1) Learners regard ChatGPT as a useful programming learning resource and rely on it to guide their learning process. (2) Learners tend to copy debug error messages to ChatGPT and copy its feedback, which may potentially weaken their deep understanding of the code. (3) High-performing group learners use ChatGPT more frequently for programming assistance while low-performing group learners use ChatGPT the least. Based on the findings, this study proposes suggestions for using ChatGPT to assist college students in programming learning.

## Introduction

In recent years, the rapid development of technology has led to the widespread application of artificial intelligence (AI) in various fields. In education, the Chat Generative Pre-trained Transformer (ChatGPT), a generative AI tool, has sparked discussions. As an intelligent conversa tional system based on large language models, ChatG PT can assist learning and teaching through input, interaction, and generation of natural language text, providing students and teachers with convenient and efficient learning  tools (Zong et al., 2023). One notable capability of ChatGPT is its efficient code generation, which allows it to assist programmers with code completion, documentation generation, chatbot development, and code generatio n from text. Moreover, ChatGPT can be integrated in to programming environments, improving developers’ efficiency (Yilmaz et al., 2023a). Despite the growing interest in programming education, learning programming remains a challenging and complex process for college learners (Yusoff et al., 2020). During programming, learners often struggle with debugging and requir e guidance. However, generative AI tools like ChatGPT can quickly offer  solutions to programming problems, providing basic correct answers  and guidance to learners  (Yu et al., 2023). Furthermore, an in-depth analysis of learners' programming processes can assist teachers and learners in adopting more effective teaching strategies and learning methods. Therefore, this research aims to collect and enco de learners' learning behaviors  when using ChatGPT for programming activities from a behavior analysis perspective. Multiple learning analysis methods will be used to explore different behavior patterns  among learners with different  levels of performance. Its purpose is to examine the application effects of ChatGPT in universities and to offer new ideas to improve the effectiveness of programming courses.

## Literature review

ChatGPT in programming education Unlike traditional programming tools, ChatGPT, as a n AI language model, allows users to communicate us ing natural language, even without programming knowledg e (Surameery et al., 2023). Open AI states that ChatGPT understands user requirements and responds accordin gly (Open AI, 2023). Typically, traditional programming tools consist of software development environments,  programming languages, libraries, and other relate d components. This requires learners to have specific programming knowledge  (Ray et al., 2014). For example, Python IDE is specifically designed for the Python language and requires learners to understand its basic concepts and operations. Although cross-platform integrated development environments like F lutter or Microsoft Visual Studio support multiple languages, they still require learners to know specific syntax and concepts to operate. The efficacy of ChatGPT in programming education is  a debatable topic with varying perspectives. On the one hand, researchers emphasize the various advantages that ChatGPT offers compared to other programming tools. These advantages include providing convenien t access, offering quick responses, facilitating pe rsonalized learning, supporting multiple languages, providing clear explanations and programming examples, allowi ng for queries and searches, and offering advanced topic r esources (Lock, 2023). ChatGPT has been found to enhance students' computational thinking, programming self-efficacy, and motivation (Yilmaz et al., 2023b). Researchers have fo und that with the support of tools like ChatGPT (ma inly through providing code explanations and debugging), programming training can effectively im prove students' programming skills (Chen et al., 2023). On the other hand, there are limitations to using ChatGPT in programming education. Yilmaz and Karaoglan (2023a) emphasize several limitations including unstructured learning, reliance on auxiliary tools and environments due to the lack of application programming, and limited  support for data structures and algorithms. Additi onally, according to Rahman and Watanobe's (2023) research, ChatGPT has some benefits when used in pr ogramming education. However, it also has its limitations, such as the absence of common sense, potential biases, challenges in complex reasoning, and the incapability to handle visual information. Researchers also emphasize that the ethical concerns associated with ChatGPT (such as b iases, discrimination, privacy, security, technolog y misuse, transparency, and societal impact) are complex and require careful consideration (Tian et al., 2023). Programming learning process analysis There is a growing emphasis on using various learni ng analytics methods to assess the programming proc ess, in addition to the programming outcomes that are typically the primary focus in programming education. Evaluating the learning process can reveal the essence of promoting the programming quality of  learners through practice (Pereira et al., 2020). Research shows that formative assessment and summative assessment complement each other to provide a comprehensive understanding of learners' programming process and performance.  Through a comprehensive assessment, researchers can gain bett er insight into programming phenomena and the under lying factors that influence the process (Sun et al., 2021a). Therefore, in the evaluation of programming education, it is important to assess students' programming abilities  using various analytical methods, focusing not onl y on final outcomes but also on performance during the learning process. Various analytical methods have been used in previous empirical studies to illustrate different aspects of the programming learning pro cess. Turkle et al. (1992) conducted a study that identified two distinct cogn itive patterns in the process of programming learning: pa tchwork and planned. Patchwork learners usually find solutions gradually through small and incremental d ebugging and code modifications, making minor chang es every time. In contrast, planned learners tend to d esign a complete solution before coding and make la rger code edits at each iteration, resulting in r elatively fewer debugging instances.  Berland et al.  (2013) used learning analytics and data mining to investigate how learne rs transition from exploration, and patching, to refinement in the learning process. The results revealed that learners in the exploration phase produced more low-quality programs compared to the other two phases, where  program quality was significantly higher. Wu et al.  (2019) used quantitative ethnographic methods to analyze t he collaborative programming process. The study fou nd that the high-performing group exhibited systematic computational thinking skills, whereas the low-performing group primarily demonstrated "patching or guessing" as th eir main computational thinking skill characteristi cs. Sun et al. (2021b) employed a mixed-methods method (clickstream analysis, lag sequential analysis, and  quantitative content analysis) to study the behavior, discourse,  and cognitive levels of three groups engaged in pa ired programming. The results revealed that the high-performance group, the medium-performance group, and the low-performance group exhibited different characteristics in terms of social interaction, cognitive engagement, and final programming performance. Wang et al. (2023) used ChatGPT to evaluate and provide feedback on the argumentative content of 50 student papers. They em ployed a grounded analysis methodology to compare feedback effectiveness in terms of precision and type. The a forementioned research indicates that multiple learning analytics methods can be applied to analyze students' programming learning process, which can help showcase different dimensions of programming learning outcomes.

## Research questions

Given that the characteristics of learners who use ChatGPT for programming learning have not been fully explored yet. Therefore, the purpose of this research is to use learning analytics techniques to collect, analyze, and mine fine-grained data on learners' programming behaviors during the learning process. Additionally, the research aims to provide guidance and recommendations for using ChatGPT as an assistive tool for programming learni ng by exploring the reasons behind these behaviors. The specific research questions are as follows:

1. What are the behavior patterns exhibited by learners when using ChatGPT for programming learning?

2. What are the characteristics of programming beha viors exhibited by learners with different

performance when using ChatGPT for programming learning?

## Participants

The study focused on 15 sophomore students majoring in Educational Technology at a normal university in China, enrolled in the major required course "Object-Oriented Programming" during the spring semester of 2023. Among the participants, there were 7 male students and 8 female students. The research sample included the b ehavioral data of individuals who were using ChatGPT to learn  programming.  The teaching process was conducted throughout five class  sessions, with each session lasting 80 minutes. During the first class, the instructor introduced the ChatGPT platform and basic knowledge  of Python. In the following four sessions, students were required to complete four programming projects using ChatGPT. Additionally, the class consisted of a total of 40 students. Midterm test scores grouped students into high-performance group (HP), medium-performance group (MP), and low-performance group (LP) in the Python course. Data from five randomly selected students in each group were analyzed.

Instrument In this study, PyCharm was primarily used as the integrated development environment for Python. Regarding the use of ChatGPT, the study adopted the self-deployed open-source project "ChatGPT Next Web". This project was developed based on the Open AI Open Application Pro gramming Interface (API) and presented in the form of a fully functional standalone website. All students used the gpt-3.5-turbo model. Students could input any question in the main window and receive feedback from ChatGPT (See Figure 1). Figure 1 A Self-adapted ChatGPT Platform

## Data collection and analysis

The study primarily collected learners' behavioral data during the programming process and then analyzed them. Initially, screen recording software (without audio) was used to capture students' programming behavio rs during the last four sessions of the course (Romance of the Three Kingdoms characters statistics word cloud project and web scraping project, and two open programming projects were selected by students), resulting in a total of 3,600 minutes of video data (60 minutes per learner). Cli ckstream analysis was employed to analyze this data  and identify students' programming behaviors (Filva et al., 2019). The video analysis followed an iterative coding process based on a previously validated coding framework (Sun et al., 2021). Two coders independently watched the screen recording videos to establish initial co des for the programming behaviors. Then they discussed and reached a consensus on the final coding framework (see Table 1). Finally, the two coders independently coded the data again in chronological order based on the coding framework, marking the learners' behaviors e very 10 seconds and cross-checking the coding results. The inter-rater reliability between the two coders was 0.80, indicating that the coding scheme was clear and exhibited good consistency. Therefore, using this coding scheme as the standard, the researchers annotated the coll ected samples of programming learning processes as the data source for subsequent analysis.

## Discussion and implication

ChatGPT can assist students in programming learning From the results of descriptive analysis and lagged sequence analysis, it can be observed that learners often copy the error messages from the console and paste them into ChatGPT, seeking help and answers. This finding aligns with the conclusion drawn by Chen et al.,  (2023), indicating that learners perceive ChatGPT as a valuab le programming learning resource and depend on it to g uide their learning process. Additionally, learners demonstrate a certain level of trust in the quick r esponse and accuracy of ChatGPT by choosing to use it after directly debugging the code or reading error messages from the console. Therefore, the following aspects should be taken into consider ation when learners use ChatGPT for programming learning. Firstly, in the initial stage s of programming, learners can make full use of Cha tGPT's assistance to deepen their understanding of programming problems and find solutions. Secondly, learners should gradually increase the frequency of independently editing code to improve their programming skills and proficiency as learning progresses. Finally, being cautious about becoming overly dependent on C hatGPT is important. Beginner students should spend more time mastering the basics of programming before starting to use AI tools, regardless of their overall performance level. ChatGPT should be used correctly as an auxiliary tool for learning and solving programming problems.

Potential problems in ChatGPT-assisted programming learning Learners tend to copy and paste error messages when using ChatGPT for assisted programming learning. It can hinder learners from solving related problems and w eaken their understanding and mastery of the code. The powerful computing capabilities of ChatGPT can lead  to limitations such as "substituting student think ing" and "excessive technological dependence". When learners mechanically copy and paste, they may fail to comprehend the logic and functionality of the code, thus makin g it difficult for them to make necessary modificat ions or debugging (P ereira et al., 2020). Therefore, in order to effectively use ChatGPT for programming learning, learners should learn to (1) Understand the logic of the code. It means taking the time to read and understand the logic and functionality of the code  rather than simply copying and pasting error message s. Understanding the purpose and relationships of each statement to deep en the understanding of the code  through analyzing the code line by line. (2) Actively think and solve the problem. Students don't rely solely on the answers or solutions provided by ChatGPT when encountering programming problems. Attempt to think independently about possible solutions, and try to solve the problems on your ow n. If encountering difficulties, students can seek help from ChatGPT, but ensure that understand the answers provided by ChatGPT and attempt to apply them to the practical questions. (3) Pose specific questions. Providing specific details and context information rather than just copying error messages when asking questions to ChatGPT. It helps ChatGPT better understand the problem and provide targeted solutions. By deeply understanding the cod e, actively thinking and problem-solving, modifying and debugging the code, and posing specific questions, learners can make better use of ChatGPT fo r programming learning and enhance their understanding and mastery of the code. Different performance groups have different behavior patterns using ChatGPT According to the results from the programming behavior distribution, we found that there were differences in the behavioral characteristics of different performance  groups during the programming learning process. Th e HP group exhibited the highest frequency of ChatGPT us age behaviors, while the LP group showed the lowest. Additionally, the HP group focused on actively editing code and using ChatGPT for assistance, the MP group leaned towards using ChatGPT to assist in programming. While the LP group had the least usage of ChatGPT for programming assistance and exhibited more other behaviors. The reason for this could be that the HP group is more proactive, has a faster learning pace, and interacts more frequently with ChatGPT within t he same time. However, the LP group may have limitations in understanding knowledge and difficulties in communicating with ChatGPT, leading to lower learning initiative and other behaviors. The MP group falls between these two levels. Therefore, ChatGPT can be a useful tool for learners during the programming learning process, but it also requires guidance from teachers to allow learners of different performance levels to make reasonable use of it and improve their programming skills and learning outcomes.

Specifically, the following strategies can be adopted for learners with different performance levels when using ChatGPT for programming learning. (1) HP group learners often possess strong independent thinking and problem-solving skills. They can use ChatGPT as an auxiliar y tool to provide insights for solving complex programming problems. (2) MP group learners also frequently use ChatGPT for assisted programming, indicating that they may not have the necessary foundational k nowledge and problem-solving abilities. When encountering programming problems, they can first think about their existing knowledge to find the essence of the problem and possible solutions, and then attempt to edit code on their own to solve the problem. They can se ek help from ChatGPT when encountering difficulties. They can also leverage various learning resources such a s books, tutorials, etc., to address problems. (3) LP group learners need teachers to provide scaffolding for asking questions to ChatGPT. It ensures that they can receive assistance and guidan ce timely when they are unable to effectively use ChatGPT (Sun et al., 2021a).

## Conclusion

This study focused on 15 sophomore students from a normal university in China. The researchers collected learning process data from these students during th eir programming tasks through screen recording and platform logs. Different learning analysis methods were empl oyed to analyze and compare the students' programmi ng learning processe s. A coding scheme for programming behaviors was devel oped by analyzing the learners' programming processes. This scheme was used to analyze the distribution of programming behaviors among learners, and the differences in behavior patterns among learners  with different performances. Based on these differences, suggestions were put forward on how to  better use ChatGPT for programming learning, aiming to enhance the effectiveness of programming learning and promote the development of higher-order thinking skills. However, the study also had some limitations, such as a small sample size and a homogeneous distribut ion of learners in terms of age and major. These limitatio ns will be explored and improved in future research. Future studies will further investigate and refine these c onstraints to better use ChatGPT as a powerful tool to support students' programming learning.
