# Cognitive Load and Testing Effect: An Exploratory Study

**Conference:** ISLS 2024

## Abstract & Introduction

### Abstract
The study explored the testing effect’s impact on subsequent test performance. It examined this effect's variability among 310 elementary students based on knowledge complexity, using tasks with differing interactivity levels. Tasks with low interactivity yielded superior performance in both immediate and delayed tests. Additionally, example-problem tasks outperformed example-example tasks in delayed tests. The study concluded that the interplay between interactivity and the testing effect remains uncertain, advocating for managing cognitive load within working memory boundaries.

Cognitive load theory is an instructional perspective based on human cognitive architecture (Chen, et al., 2023). Leahy y Sweller (2019) explored why tests (Kornell et al., 2012) often result in better performance compared to an equivalent number of study sessions. The findings confirmed the effectiveness of tests compared to merely reviewing the study material, particularly in complex tasks. The impact of tests on complex tasks (e.g., example-problem pairs) was significantly more pronounced in delaye d assessments (one week later) than in immediately administered tests. However, in simpler tasks (e.g., example-example pairs), this effect was not observed. These considering the depletion of working memory resources.  However, Leahy and Sweller (2019) used two different specific knowledge domains, one for each level of element interactivity. Therefore, it is unclear whether the testing effect on complex tasks or its absence in simpler tasks pertains to the same specific knowledge domain. Consequently, this study focused on examining the effects of task sequence (e.g., example-example vs. example-problem) and test timing (e.g., immediate vs. delayed) on learning tasks with low and high element interactivity within the same specific knowledg e domain. The hypothesis was that, in tasks with high element interactivity, using tests (e.g., example-problem) instead of restudying (e.g., example-example) reduces performance due to the depletion of working memory resources immediately after a learning session. However, performance improves in a delayed test due to retrieval. Nevertheless, these effects disappear in low element interactivity tests.

## Method

The study included 310 students from a primary school in Ecuador. It was used a factorial design considering the variables of the task sequence (example-example vs. example-problem), the interactivity of the elements (high vs. low) and the test time (immediate vs. delayed).  The study used materials that included an acrostic poem as a worked example. The evaluation of the poem focused exclusively on the content taught during instruction, classifying it into two categories according to its use of knowledge with high or reduced interactivity of elements. Analyzes were performed using SPSS version 26 for Windows. A 2 (element interactivity: high vs. low) x 2 (type of study: example-example vs. example-problem) analysis of variance (ANOVA) was used. Descriptive results are presented in Table 1. A significanc e level of 0.05 was used, and for effect size, partial eta-square was used (0.01, 0.06, and 0.14).

Regarding the immediate test, the 2x2 ANOVA revealed a significant main effect for item interactivity, F (1,163) = 5.09: MSE = 6.74: p = 0.03: η p2 = 0.03. It suggests that learning with low-interactivity tasks is better than with high-interactivity tasks. The main effect of study was not significant. It suggests that learning with example – example tasks produces a cognitive benefit similar to learn ing with example – problem tasks. The interaction between both effects was not significant.

For the delayed test, the main effect for item interactivity was significant, F(1, 139) = 12.47; MSE = 5.63; p < 0.01; ηp2 = 0.08, indicated that learning with low-item interactivity tasks is better than high-item interactivity tasks, such as the immediate test. The main effect of study, as opposed to immediate test, was significant, F(1,139) 2367 = 4.76; MSE  = 5.63; p = 0.03; ηp2 =  0.03. It suggests that studying with example – problem tasks is better than with example – example tasks. The interaction between both effects was not significant, F(1, 139) = 0.05, MSE = 5.63, p =.82, ηp2 <  0.01.
