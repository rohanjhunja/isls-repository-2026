# Modelling Complex Learning Interactions—A Hands-on Workshop on Heterogeneous Interaction Network Analysis (HINA)

**Conference:** ISLS 2026

## Abstract & Introduction

### Abstract
Learning is inherently a complex, multi-faceted process situated across learners, tools, and environments. This workshop introduces HINA (Heterogeneous Interaction Network Analysis), a methodological framework for modeling and analyzing complex learning interactions through networked relationships across diverse entities such as students, behaviors, and artifacts. By representing learning process data as heterogeneous interaction networks, HINA provides researchers with a means to uncover latent patterns, measure theoretical constructs, and derive actionable insights into learning processes. This half-day workshop features interactive discussions and a hands-on tutorial with the HINA webtool (hina-network.com), enabling participants to analyze their own data, followed by featured case studies and collaborative discussion on future applications in learning sciences. This workshop will contribute to the learning sciences community by disseminating a novel open-source tool for analyzing complex learning interactions, enhancing the methodological capacity for theoretical development.

Heterogenous Interaction Network Analysis (HINA) Constructivist learning theories posit that knowledge is actively built by learners through interactions with their environment (Vygotsky, 1978; Piaget, 2013). At its core, learning is an interactive process emerging from a student's engagements with peers, instructors, and pedagogical tools (Bandura & Walters, 1977; Chi, 2009). These interactions are inherently heterogeneous, forming a network of relationships among diverse entities—such as students with learning artifacts. These heterogenous interactions constitute the very fabric of the learning process and provide critical insights into student engagement and the impact of learning environments. To unlock these insights, there is a critical need for analytical methods capable of modeling these complex interactions to drive theoretical development in learning sciences.

HINA (Heterogeneous Interaction Network Analysis) is a novel learning analytics framework designed for modeling, analyzing, and visualizing heterogeneous interactions in learning processes (Feng et al., 2025a). It formalizes multi-entity interactions in learning processes as Heterogeneous Interaction Networks (HINs), where nodes represent distinct entities—such as students, artifacts, or coded behaviors—and edges represent the relationships between them, such as engagement or association (see examples in Figure 1). Existing networkbased learning analytical methods such as Epistemic Network Analysis (ENA) provide effective tools to analyze the relationships among a single type of nodes, for instance, modelling the co-occurrence of theoretical constructs within each pre-defined time window using dialogue data (Shaffer et al., 2016). HINA is fundamentally different in its focus on interactions between diverse entity types and in its suite of original analytical methods, which are tailored to measure and identify the underlying characteristics and patterns of the studied heterogenous learning interactions.

HINA includes three-level original analytical methods, including 1) node-level analysis for measuring the quantity and diversity of interactions; 2) dyadic-level analysis for identifying statistically significant edges under a specified null model; 3) meso-level analysis for clustering nodes based on their heterogenous interaction patterns with a novel non-parametric clustering method. In addition, HINA offers an interactive network visualization for presenting the analytical results and customizing network visualizations for feeding back the learning analytics results (see an example in Figure 2). Researchers can access these functions: by installing the HINA Python package (pip install hina) or by accessing the user-friendly HINA web tool at hina-network.com, which requires no coding experience.

As a peer-reviewed and empirically validated framework (Feng et al., 2025a; Feng et al., 2024; Feng et al., 2025b), HINA offers a flexible tool for modeling heterogeneous interactions across diverse learning contexts. Its applicability is especially pertinent to the growing field of human-AI collaboration. HINA provides an innovative method for analyzing student-AI interactions, enabling researchers to quantify contributions, identify engagement patterns, and detect key relationships. These capabilities offer new perspectives for understanding human learning with AI and for studying the dynamics of human-AI hybrid intelligence (Cukurova, 2025), positioning HINA as a valuable methodological tool for advancing the theoretical understanding of complex learning interactions in AI-assisted learning environments.
